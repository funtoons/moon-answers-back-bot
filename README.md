Entry for the [make.fun bounty "The Moon Finally Answers Back"](https://make.fun/bounty/u-mang-the-moon-finally-answers-back-781a7ec1): one line, 1 to 240 characters, in the voice of the Moon replying at last to the wishes, howls and late-night promises of everyone staring up at it.

## How it works

`main.py` is deterministic and offline: it writes a single fixed line of text to `/output/entry.txt`. No randomness, no network, no timestamps — two runs produce byte-identical output.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
